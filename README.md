# Wayfem 🌍

**Cloud Run (live during hackathon):** https://wayfem-app-3oetgfjgkq-uc.a.run.app

> **Multi-Agent AI System for Solo Female Travel Planning**
> *Wayfem = wayfare + feminine* — Hackathon submission, Google-native AI stack, built around five LLM agents and five MCP servers.

---

## What it does

You describe a trip in plain words. Wayfem turns it into a vetted, day-by-day itinerary in ~25 seconds — every flag sourced, every hotel scored on a Female Friendliness Index, every emergency number web-checked against Wikipedia, every community tip linked back to the original Reddit thread.

It's not a chatbot. It's a **5-agent system** with **5 MCP servers** connecting to real APIs (Google Maps, Serper, Reddit, Google Calendar, Serper Images), live-streamed over SSE, with a grounded RAG chat ("Ask Wayfem") that knows *your* trip.

```
                User describes trip →  /api/v1/plan/clarify  (LLM feasibility gate)
                                                    ↓
                            /api/v1/plan  (LangGraph StateGraph fan-out)
                                                    ↓
        ┌──────────────────────┬──────────────────────┬──────────────────────┐
        │                      │                      │                      │
   Safety Agent          Stays Agent          Community Agent          Briefing Agent
   • advisories          • FFI scoring         • Reddit MCP RAG         • currency
   • recent incidents    • multi-city          • r/femaletravels        • do's/don'ts
   • crisis lines        • security features   • r/solofemaletravellers • dress code
   • emergency numbers   • female-owned tag    • author attribution     • "what if" scenarios
        │                      │                      │                      │
        └──────────────────────┴───────────┬──────────┴──────────────────────┘
                                           ↓
                                   Schedule Agent
                                   • curfew-aware (LOW≤23, MED=22, HIGH=21)
                                   • transport modes A→B (Distance Matrix)
                                   • cost estimates
                                   • Google Maps place_id per activity
                                           ↓
                                   Final Rank → Firestore → SSE complete event
```

Everything runs in a **single Docker container** on Cloud Run: React frontend baked at build time, FastAPI serves both API and static assets, Calendar MCP runs as a background subprocess (`start.sh`), Reddit MCP spawned on-demand by the community agent (`npx`).

## Highlight reel

| Feature | What's behind it |
|---|---|
| **Clarification + feasibility gate** | LLM with structured Pydantic output rejects unrealistic plans ("10 cities in 3 days") and asks targeted personalisation questions. Multi-select cities + interests. |
| **Web-searched emergency numbers** | Recency-filtered Serper search restricted to Wikipedia + .gov sources. LLM extracts only from `[OFFICIAL SOURCE]`-tagged snippets, returns "unknown" before guessing. Verified for Egypt (122/123/180), Japan (110/119), Thailand (1155/1669/199). |
| **Recent incidents** | Past-30-day search via `tbs=qdr:m`. Severity-tagged (info / caution / alert) with source URL. |
| **Reddit MCP RAG** | `npx -y reddit-mcp-server` (anonymous mode) — markdown-output parser. Community agent distills tips, paraphrases bodies, links every tip back to the actual Reddit thread with author attribution. |
| **Female Friendliness Index** | Per-hotel 0–10 score from Gemini analysis of solo-female reviews + security features + area safety + female-staff signals. Tooltip on hover. |
| **"What if" rehearsals** | 3–5 destination-specific role-plays generated by the briefing agent — each with a suggested response and a useful local-language phrase. Pre-trip confidence-builder. |
| **Crisis & legal directory** | Women's hotline, sexual-assault helpline, tourist police, embassy registration — populated from a dedicated Serper query. |
| **Nearest police/hospital** | One-click directions URL built from `place_id`, with distance in km. Sourced from Google Maps Places Nearby. |
| **Multi-city orchestration** | Hotels searched per-city, tagged with `search_city`, grouped under city headers in the UI. |
| **Transport between every stop** | Pairwise Distance Matrix call selects walking ≤1.2km / transit ≤8km / rideshare with cost hint. |
| **Per-activity cost** | Gemini estimates per-person cost in local currency. Daily totals, trip total badge. |
| **Google Maps deep-links** | Every itinerary location is geocoded to a real `place_id` — clicking opens Maps to that exact venue. |
| **Ask Wayfem (grounded RAG chat)** | `POST /api/v1/ask` — stateless, takes a compact trip-context blob (safety report + briefing + top tips + day-1 itinerary) and returns 2–4-sentence answers that cite sources from your own data. Floating widget; per-trip localStorage history. |

## Quick start

### 1. Configure environment

```bash
cp backend/.env.example backend/.env
# Fill in your API keys
```

| Variable | Required | Description |
|---|---|---|
| `GOOGLE_CLOUD_PROJECT` | ✓ | GCP project ID (must match deploy target) |
| `GEMINI_API_KEY` | ✓ | Gemini API key (project must have `generativelanguage.googleapis.com` enabled) |
| `GOOGLE_MAPS_API_KEY` | ✓ | Maps Platform API key (geocoding + distance-matrix + places enabled) |
| `SERPER_API_KEY` | ✓ | Serper.dev — powers safety / advisory / recent-incidents / image search |
| `GOOGLE_CALENDAR_CREDENTIALS_JSON` |   | Path to Calendar OAuth JSON (optional, only for /add-to-calendar) |
| `GOOGLE_APPLICATION_CREDENTIALS` |   | Path to service-account JSON (Firestore — optional locally) |
| `ENABLE_WEB_SEARCH` |   | Defaults `true`; set `false` to disable Serper calls |
| `CORS_ORIGINS` |   | JSON array, e.g. `["http://localhost:5173"]` |

> **Note:** `gemini-3-flash-preview` is the active model. The deploy script enables `generativelanguage.googleapis.com` for you. Make sure your API key has *no* HTTP-referrer or IP restrictions (Cloud Run egress IPs rotate).

### 2. Local development (hot reload)

```bash
docker-compose up --build
```

| Service | URL |
|---|---|
| Frontend (Vite dev server) | http://localhost:5173 |
| Backend API | http://localhost:8000 |
| API docs | http://localhost:8000/docs |
| Calendar MCP | http://localhost:8003 |

### 3. Test the deploy image locally

Run the exact image that ships to Cloud Run:

```bash
./test-combined.sh                # build (with MCP verification) + run
./test-combined.sh build          # rebuild only
./test-combined.sh smoke-reddit   # boot the Reddit MCP and confirm it responds
```

Open http://localhost:8080. First build is ~3 minutes (frontend + Python + `npm install -g reddit-mcp-server`).

**Backend:**
```bash
cd backend
python -m venv venv && source venv/bin/activate
pip install -r requirements.txt
python mcp_servers/calendar_server.py &           # background
uvicorn main:app --reload --port 8000
```

**Frontend:**
```bash
cd frontend
echo "VITE_API_BASE_URL=http://localhost:8000" > .env.local
npm install && npm run dev
```

## Deployment (Google Cloud Run)

Single service, single image, single URL.

```bash
./deploy.sh                # full: preflight + secrets + build + verify image + push + deploy + smoke
./deploy.sh verify         # preflight env + verify built image (no upload, no deploy)
./deploy.sh secrets        # create/update Secret Manager secrets only
./deploy.sh build          # build & verify image only
./deploy.sh deploy         # deploy already-pushed image + smoke test
./deploy.sh smoke          # run smoke tests against the live service
```

**What `step_prerequisites` enables on your project:**
- `run`, `artifactregistry`, `secretmanager`, `firestore`
- `generativelanguage` (without it: `API_KEY_INVALID`)
- `geocoding-backend`, `distance-matrix-backend`, `places-backend` (Maps Platform legacy)
- `routes` (forward-compat with the new APIs)

**What `step_preflight` checks:**
- `GEMINI_API_KEY`, `GOOGLE_MAPS_API_KEY`, `SERPER_API_KEY` — non-empty after whitespace trim, prints last-4-chars fingerprint so you can visually verify
- `GOOGLE_CLOUD_PROJECT` — matches deploy target
- Robust `.env` parser handles JSON-ish values like `CORS_ORIGINS=["…"]`

**What `step_smoke` verifies after deploy:**
1. `/health` returns 200 within 30s (with retries).
2. `/api/v1/safety/Cairo%20EG` returns real Egyptian numbers (122 police, 123 ambulance, 180 fire) — *not* the `112` fallback. If it does return `112`, prints the three most likely Gemini-key fixes (API restrictions / wrong project / IP-bound key).

The deploy step uses 2 vCPU / 2 GB RAM, **`--cpu-boost` for cold starts**, **10-min request timeout** (multi-city plans can run ~5 min), and binds `roles/datastore.user` + Secret Accessor to the runtime service account.

### Example: plan a trip

```bash
curl -X POST https://wayfem-app-3oetgfjgkq-uc.a.run.app/api/v1/plan \
  -H "Content-Type: application/json" \
  -d '{
    "destination": "Bali, Indonesia",
    "start_date": "2026-06-01",
    "end_date": "2026-06-07",
    "cities": ["Ubud", "Seminyak"],
    "preferences": {"pace": "balanced"},
    "emergency_contact": "Jane Doe +1-555-0100"
  }'
```

The response is a Server-Sent Events stream of `agent_start`, `agent_event`, `agent_complete`, and a final `complete` event with the full `TripPlanResponse`.

## Agent architecture

### LangGraph StateGraph

```
parse_request
     ↓
fetch_search_data  (parallel: search_safety + search_advisory + search_hotels +
                              area_safety + search_safety_local + search_emergency +
                              search_recent_incidents + search_crisis_directory)
     ↓
[fan-out]
     ├── safety_check       (run_safety_agent)
     ├── hotel_search       (run_accommodation_agent)
     ├── community_lookup   (run_community_agent + Reddit MCP RAG)
     └── briefing           (run_briefing_agent — currency, do's, scenarios)
     ↓
merge_results  (fan-in)
     ↓
build_schedule  (run_schedule_agent — curfew-aware, transport modes, costs, place_id)
     ↓
final_rank  (CRITICAL → blocked, HIGH → flagged, FFI < 4 hotels filtered)
     ↓
store_db  (Firestore)
```

### Five MCP servers

| Server | Transport | Tools | Purpose |
|---|---|---|---|
| **Maps** | stdio subprocess | `geocode`, `search_hotels`, `place_details`, `area_safety` | Google Maps Platform |
| **Search** | stdio subprocess | `search_safety`, `search_advisory`, `search_hotel_safety_reviews`, `search_emergency` | Serper.dev (recency filters available via `tbs=qdr:m`) |
| **Reddit** | stdio (`npx -y reddit-mcp-server`) | `search_reddit`, `get_top_posts`, `get_user_*` | Anonymous-mode Reddit reads, pre-installed in image |
| **Calendar** | HTTP `:8003` | `create_event` | Google Calendar — started by `start.sh` |
| **Photos** (REST proxy) | HTTP `/api/v1/place-photo` | image-search proxy | Real activity photos from Serper Images, server-side cached |

### Safety guardrails

- `CRITICAL` threat → destination blocked, alternatives suggested
- `HIGH` threat → red banner, user acknowledgment, curfew = 21:00
- `MEDIUM` curfew = 22:00, `LOW` curfew = 23:00
- Hotels below FFI 4.0 hidden unless no alternatives
- Risk flags rendered as: *"According to [Source], …"* with clickable source URLs
- Every itinerary day has a safe return time
- `recent_incidents` show severity-tinted chips; `nearest_police` and `nearest_hospital` are one-click Maps directions

### Female Friendliness Index (FFI)

| Factor | Weight |
|---|---|
| Solo female review sentiment | 35% |
| Area safety score (proximity to police, hospital) | 25% |
| Security features (locks, cameras, 24h desk, lobby visibility) | 20% |
| Female staff / ownership | 10% |
| Emergency proximity | 10% |

Hover the FFI badge in the UI for the full explainer.

## Resilience & graceful degradation

Production-class safety nets so a single misbehaving dependency doesn't kill the agent:

- **Reddit MCP unavailable** → community agent falls back to AI-only generation; `source` field marks each tip.
- **Maps legacy API not enabled** → maps_tool's circuit breaker flips on the first `REQUEST_DENIED`, subsequent calls short-circuit, agent ships an itinerary without place_ids and the UI falls back to text-search Maps URLs.
- **Cloud Run drops idle TLS** → `geocode_place_id` and `_distance_matrix_with_retry` reset the cached `googlemaps.Client` and retry with backoff.
- **Gemini truncates JSON** → accommodation agent walks brace depth to salvage hotel objects from partial responses; community agent retries with bumped tokens; bumped budgets across the board (safety: 6k, schedule: 16k, accommodation: 12k).
- **LLM hangs** → schedule agent's Gemini call has a 240s SDK timeout + 260s `asyncio.wait_for` outer guard so SSE never stalls forever.
- **Place_id enrichment slow** → 30s wall-time cap on the parallel geocoding pass.
- **Firestore unavailable locally** → tips persist in-memory; agent still ships.

## Hackathon demo flow

1. Open the home page. Type *"A week in Bali — temples, beaches, food."* Pick dates.
2. Clarification AI parses → asks *"Which cities?"* with multi-select chips. Pick Ubud + Seminyak. Confirm.
3. The 4-agent dashboard lights up in parallel; **"Did you know · What is FFI?"** rotates underneath while you wait.
4. ~25 seconds later: results page.
5. **Trip briefing panel** above the tabs — currency, climate, dress code, do's/don'ts, **"What if"** rehearsals with local-language phrases.
6. **Card-style tabs** show live counts at a glance: `7 days · 28 activities` · `8 hotels · top FFI 9.2` · `8 tips · 4 from Reddit` · `LOW · 4 flags`.
7. Itinerary cards show transport-mode pills (`🚇 12 min · ~Rp 5,000`), cost chips, clickable Maps location names. **Refine** input: *"remove the museum, add more food stops"* → schedule agent re-runs live.
8. **Safety tab**: emergency number `122 police · 123 ambulance · 180 fire` (web-sourced, not LLM-guessed), nearest police/hospital with directions links, recent-incident chips (past 30 days, severity-tinted), crisis & legal contacts with click-to-call.
9. **Community tab**: tips with orange `r/femaletravels` chips → opens the actual Reddit thread.
10. **Ask Wayfem** floating button → *"Is it safe to walk back to my hotel after 10pm?"* → answer references your specific Ubud streets and cites the briefing.
